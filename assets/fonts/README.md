# Plus Jakarta Sans Font

This directory should contain Plus Jakarta Sans font files in .woff2 format.

## Required Files

Download from Google Fonts or official source:
- PlusJakartaSans-Regular.woff2 (400 weight)
- PlusJakartaSans-Medium.woff2 (500 weight)
- PlusJakartaSans-SemiBold.woff2 (600 weight)
- PlusJakartaSans-Bold.woff2 (700 weight)

## License

## Note

For development, the application will fall back to Inter and system fonts
if these files are not present. For production builds, ensure all required
font weights are bundled.
